## 0. 总体判断

本轮不应以“语言润色”为主，而应按“方法定义 - 模型闭合 - 对比验证 - 结论降阶/增强”的大修逻辑重构。当前稿件已经比审稿意见中描述的旧版更克制：经济评价数值已经基本撤回，正文也强调样例贯通。但这同时带来一个新问题：稿件的工程结论被压得太低，导致贡献只剩“链路打通”。因此，大修目标不是继续弱化，而是补足可验证证据，让“链路打通”升级为“可复核的规划方案生成与比选方法”。

建议将论文定位明确为：

> 面向采区规划的 ODI 约束型方案生成与多目标比选方法论文。

不建议定位为：

- 覆岩力学机理论文；
- 纯优化算法论文；
- 工程经济评价论文；
- 软件系统说明论文。

建议把“覆岩扰动”子项改名，避免 ODI 总指标和子指标语义重叠。可改为：

### 2.2 权重与阈值证据

当前表1给出 `0.45/0.30/0.25`，项目导出材料中部分场景又有 `0.15/0.25/0.60`。这会被审稿人抓住。必须统一解释：

- 若研究主线是“全覆岩扰动综合规划”，主文采用 `0.45/0.30/0.25`；
- 若研究主线是“含水层扰动约束规划”，主文采用 `0.15/0.25/0.60`；
- 两者不能混用。若保留多个场景，必须说明“场景权重不同，综合规划使用场景组权重，含水层专项使用专项权重”。

建议新增“权重确定方法”小节，采用“专家赋权 + 敏感性检验”的保守写法：

> 权重由采区规划、覆岩控制和水文地质约束的重要性排序确定，作为基准权重；为避免结论依赖单一经验权重，进一步设置若干扰动组合开展敏感性分析。

敏感性方案建议：

| 方案 | 地表沉陷 | 含水层扰动 | 上行开采 | 用途 |
|---|---:|---:|---:|---|
| W0 基准 | 0.45 | 0.30 | 0.25 | 综合基准 |
| W1 沉陷优先 | 0.60 | 0.25 | 0.15 | 检验地表保护敏感性 |
| W2 含水层优先 | 0.25 | 0.60 | 0.15 | 检验水害控制敏感性 |
| W3 均衡 | 0.33 | 0.33 | 0.34 | 检验权重均衡情形 |
| W4 上行开采优先 | 0.25 | 0.25 | 0.50 | 检验上覆扰动约束 |

阈值建议：

| 阈值 | 主文角色 | 不宜写法 | 推荐写法 |
|---|---|---|---|
| 0.70 | 预警统计阈值 | 安全红线 | 高扰动暴露统计阈值 |
| 0.80 | 高风险统计阈值 | 工程禁止线 | 强扰动敏感区统计阈值 |
| 0.85 | 可作为稳健性测试 | 行业规定 | 严格控制情景 |

阈值敏感性至少补 `0.65/0.70/0.75/0.80/0.85` 下的超限面积比例、候选方案排序是否变化。

### 2.3 多目标模型证据

当前 1.3 节只有目标函数口径，不足以称为模型。建议重写为“决策变量 - 约束 - 候选生成 - 评价排序”四段。

决策变量建议定义为：

| 类型 | 符号 | 含义 |
|---|---|---|
| 工作面数量 | `N_f` | 生成工作面的数量 |
| 工作面宽度 | `W_j` | 第 j 个工作面宽度 |
| 推进长度 | `L_j` | 第 j 个工作面推进长度 |
| 起点坐标 | `(x_j, y_j)` | 工作面布置起点 |
| 推进方向 | `theta_j` | 推进方向角 |
| 边界/区段煤柱 | `B_b, B_s` | 边界煤柱和区段煤柱宽度 |
| 方案选择变量 | `y_j` | 候选条带是否纳入方案 |

约束建议写成集合：

- 有效布置域约束：工作面多边形必须在 `Omega_e` 内；
- 不重叠约束：任意工作面对象之间不得重叠；
- 煤柱约束：相邻工作面间距不小于 `B_s`；
- 宽度约束：`W_min <= W_j <= W_max`；
- 推进长度约束：`L_min <= L_j <= L_max`，若当前样例低于 800 m，应说明 800 m 是推荐校核阈值而非硬约束；
- 风险约束：`ODI_mean <= tau_mean` 或 `E_pi(T_ODI) <= tau_E`；
- 生产组织约束：接续顺序满足单面开采/并行掘进等规则；
- 几何连通约束：巷道与工作面形成连通网络。

目标函数建议拆成三个可计算子目标：

1. 工程效率 `S_e`：覆盖率、巷道长度惩罚、推进长度均衡性、连通性；
2. 资源回收 `S_r`：煤厚场积分、有效覆盖面积、资源价值；
3. 扰动控制 `S_m`：ODI 均值、P90、超限比例惩罚。

建议公式框架：

```text
S_e = a1*C_cov + a2*B_len + a3*B_bal + a4*B_conn
S_r = b1*R_area + b2*R_thick + b3*R_recover
S_m = 1 - (c1*ODI_mean + c2*ODI_P90 + c3*E_pi)
S = lambda_e*S_e + lambda_r*S_r + lambda_m*S_m
```

每个评分必须说明归一化区间、权重、惩罚项方向。当前表1中的“厚度0.35、顶板0.25、瓦斯0.20、水0.15、构造0.05”可以用于资源/地质适宜性评分，但不能直接等同于多目标模型权重。

## 3. 经济评价处理策略

本轮建议采用“收缩为接口传递 + 保留公式 + 不给强结论”的路线。原因是当前确认版已经撤掉 NPV 等具体数值，且审稿意见强烈质疑经济参数体系。如果强行补经济，会扩大工作量并把主线拉散。

正文建议：

- 方法中保留现金流公式；
- 结果中只说明工作面边界、推进长度、ODI 统计量可作为接续和经济评价输入；
- 表4 保留“可传递变量清单”，不再给现金流曲线；
- 讨论中说明经济评价需要真实价格、成本、税费、折现率和生产制度支撑，本文不据此做经济最优判断。
