### 1.1 正文建议稿

采区规划中的覆岩扰动风险通常并非由单一物理量决定，而是由地表沉陷、含水层扰动、上行开采安全性以及局部地质采矿条件共同作用形成。不同风险场景的原始量纲、判据和空间尺度存在差异，若分别以各自判据进入规划过程，容易造成约束口径不统一和方案比较困难。为此，本文将多场景风险先转化为无量纲分量，再通过权重聚合形成统一的覆岩扰动指数 ODI，用于候选方案筛选、排序和后续传递。

设规划域为 `Omega`，任意空间位置 `x in Omega` 处的风险分量包括地表沉陷扰动分量 `D_s(x)`、含水层扰动分量 `D_a(x)` 和上行开采扰动分量 `D_u(x)`。三类分量均经归一化处理后映射到 `[0,1]` 区间，数值越大表示扰动风险越高，则综合 ODI 可表示为：

```text
ODI(x) = w_s D_s(x) + w_a D_a(x) + w_u D_u(x)
```

其中，`w_s`、`w_a` 和 `w_u` 分别为地表沉陷、含水层扰动和上行开采分量权重，满足：

```text
w_s + w_a + w_u = 1,  w_s >= 0, w_a >= 0, w_u >= 0
```

对于原始指标中“数值越大风险越高”的正向指标，采用：

```text
X_i'(x) = [X_i(x) - X_i,min] / [X_i,max - X_i,min]
```

对于“数值越小风险越高”的逆向指标，采用：

```text
X_i'(x) = [X_i,max - X_i(x)] / [X_i,max - X_i,min]
```

当原始样本存在极端值或不同场景需要统一色标比较时，可采用分位数截断归一化：

```text
X_i'(x) = clip([X_i(x) - Q_0.05] / [Q_0.95 - Q_0.05], 0, 1)
```

式中，`Q_0.05` 和 `Q_0.95` 分别为对应指标的 5% 和 95% 分位数。该处理能够降低极端样本对 ODI 分布的支配作用，并保持不同场景之间的统计可比性。

### 1.1 方案级统计指标

设候选方案为 `pi`，其工作面布置区域为 `A_pi`，则方案级 ODI 均值为：

```text
ODI_mean(pi) = mean{ODI(x), x in A_pi}
```

方案高分位扰动值为：

```text
ODI_P90(pi) = Q_0.90{ODI(x), x in A_pi}
```

当扰动阈值为 `T_ODI` 时，超限暴露比例为：

```text
E_pi(T_ODI) = N[ODI(x) > T_ODI] / N_pi
```

其中，`N_pi` 为方案区域内参与统计的网格数量。本文建议将 `T_ODI=0.70` 作为高扰动预警统计阈值，将 `T_ODI=0.80` 作为强扰动敏感区统计阈值。二者用于方案比较和敏感性分析，不直接等同于行业安全红线。

### 1.2 正文补写段落

连续参数场构建的目的并非替代精细三维地质建模，而是将离散钻孔属性转化为能够参与采区布局评价的二维规划变量。考虑到研究区样点数量有限且规划阶段需要较强的工程可复核性，本文采用反距离加权插值方法构建煤层厚度、瓦斯含量、涌水量和相关覆岩参数场。对任意规划位置 `x`，参数估计值可表示为：

```text
Z(x) = sum[lambda_i(x) Z_i]
lambda_i(x) = d_i(x)^(-p) / sum[d_i(x)^(-p)]
```

式中，`Z_i` 为第 `i` 个钻孔样点的参数观测值，`d_i(x)` 为位置 `x` 与钻孔 `i` 的平面距离，`p` 为距离衰减指数。插值结果统一裁剪至有效布置域 `Omega_e`，并与 ODI 风险场采用相同空间参考和网格口径，以保证参数场、风险场和工作面对象之间能够叠置统计。

为检验参数场的稳定性，建议采用留一交叉验证：每次剔除一个钻孔样点，利用其余样点插值得到该点预测值，并计算平均绝对误差和均方根误差：

```text
MAE = (1/n) sum |Z_i - Z_hat_i|
RMSE = sqrt[(1/n) sum (Z_i - Z_hat_i)^2]
```

该验证不用于证明 IDW 优于 Kriging，而用于说明当前参数场在样例尺度下具备进入规划评价的基本可复核性。

### 7.2 约束条件

候选方案必须满足以下约束：

```text
F_j subset Omega_e
```

表示每个工作面对象 `F_j` 必须位于有效布置域内。

```text
F_i intersection F_j = empty, i != j
```

表示不同工作面之间不得发生空间重叠。

```text
dist(F_i, F_j) >= B_s
```

表示相邻工作面或区段之间应满足区段煤柱宽度约束。

```text
W_min <= W_j <= W_max
L_min <= L_j <= L_max
```

表示工作面宽度和推进长度应满足设计规则。若 800 m 是推荐校核值而非硬性约束，正文必须写为“推荐/校核阈值”，不能写成“均满足最小推进长度约束”。

```text
E_pi(T_ODI) <= E_max
```

表示候选方案的高扰动暴露比例不超过设定容许水平。若当前结果不能满足，则应写为“用于排序和降权”，而不是硬约束。

### 7.3 候选方案生成流程

建议正文给出算法流程：


### 7.4 多目标评分

建议把综合目标写为：

```text
max S(pi) = lambda_e S_e(pi) + lambda_r S_r(pi) + lambda_m S_m(pi)
```

其中，`S_e` 为工程效率评分，`S_r` 为资源覆盖评分，`S_m` 为扰动控制评分，`lambda_e`、`lambda_r`、`lambda_m` 为目标层权重，满足：

```text
lambda_e + lambda_r + lambda_m = 1
```

工程效率评分可写为：

```text
S_e = a_1 C_cov + a_2 B_bal + a_3 B_conn - a_4 R_road
```

其中，`C_cov` 为有效覆盖率，`B_bal` 为工作面长度均衡性，`B_conn` 为巷道连通性，`R_road` 为巷道工程量惩罚项。

资源覆盖评分可写为：

```text
S_r = b_1 R_area + b_2 R_thick + b_3 R_quality
```

其中，`R_area` 为布置面积或资源覆盖率，`R_thick` 为煤厚场积分或厚煤区覆盖比例，`R_quality` 为瓦斯、涌水量、构造等地质适宜性综合项。

扰动控制评分可写为：

```text
S_m = 1 - [c_1 ODI_mean + c_2 ODI_P90 + c_3 E_pi(T_ODI)]
```

其中，`ODI_mean`、`ODI_P90` 和 `E_pi` 分别表示方案区域内 ODI 均值、90%分位数和超限暴露比例。

## 10. 经济评价收缩稿

建议将经济评价保持为“输入接口说明”，暂不恢复现金流图和 NPV 结论。

### 方法节表述

规划结果可进一步转化为采掘接续和经济评价所需的上游输入。对工作面对象而言，其边界、面积、推进长度和 ODI 统计量可用于确定月度产量、生产顺序和风险修正系数；对巷道对象而言，其长度和连通关系可用于估算掘进工程量和准备周期。若进一步开展经济评价，第 `t` 月净现金流可表示为：

```text
NCF_t = Rev_t - Cost_t - RiskCost_t
```

式中，`Rev_t` 为收入，`Cost_t` 为常规成本，`RiskCost_t` 为与高扰动暴露或生产扰动相关的风险成本。由于当前样例尚缺少真实矿井价格、成本、税费和生产制度校核，本文不据此给出经济最优结论，仅说明规划对象向经济评价的传递关系。

### 结果节表述

当前样例已经形成工作面面积、推进长度、巷道长度和 ODI 统计量等结构化字段，可作为采掘接续和经济评价的输入。需要强调的是，该传递关系证明的是规划结果的数据组织能力，而非证明当前样例在真实矿井条件下具有经济最优性。

## 11. 讨论重写框架

建议讨论改成 4 个问题导向小节：

### 11.1 ODI 前置约束相对于后验校核的作用

重点讨论：

- 传统流程是先布置后校核；
- ODI 的价值在于让风险进入候选方案生成；
- 风险指标从图层变成方案级统计量。

### 11.2 权重、阈值和网格尺度对方案稳定性的影响

重点讨论：

- ODI 是综合指标，必须承认权重依赖；
- 敏感性分析不是附属项，而是可信度来源；
- 阈值 0.70/0.80 是统计口径，不是安全红线。

### 11.3 连续参数场质量对规划结果的影响

重点讨论：

- 钻孔密度、边界外样点、插值误差会影响资源覆盖评分；
- IDW 是工程透明方案，不是最优地质建模算法；
- 后续可用 Kriging 或三维地质建模增强。

### 11.4 方法边界

重点讨论：

- 当前仍是样例验证；
- 真实矿井需补充现场巷道、通风运输、设备能力和生产制度；
